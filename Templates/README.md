# Templates

Starting points for notes. Do not store daily logs in this folder.

- `Daily Note` is what Obsidian copies when it creates a file in `Daily/`. The date is filled in for you.
- `Bot Entry` is the block one bot pastes at the bottom of today's daily note.

To insert a template by hand: put the cursor where you want it, press Command + P, and run **Templates: Insert template**.

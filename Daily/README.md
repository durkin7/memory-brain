# Daily

One note per day. The file name is the date, like `2026-11-22.md`.

Obsidian creates today's note from `Templates/Daily Note` when you run **Daily notes: Open today's daily note** (Command + P).

Each bot adds a section at the bottom, under its own `##` heading. Add new sentences to your own section. Do not change another bot's words, and do not rewrite older days.

The rules for what to write are in `CONTRIBUTING-BOTS.md` at the root of the vault.

# Keep secrets out of the vault

## Lesson

Passwords, API keys, tokens, card numbers, street addresses, and phone numbers do not belong in this vault.

## Why

These notes are copied to GitHub and shared with bots. A secret that lands here is hard to take back, because old commits keep a copy.

## Do this instead

Keep secrets in a password manager. If a note needs to mention a login, name the service only. For example: "the website login is in the password manager."
